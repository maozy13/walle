# CLI

CLI 提供基于命令行的 Agent 应用。

## 参数

| 参数 | 类型 | 说明 |
| -- | -- | -- |
| baseUrl | string | 模型 API URL |
| model | string | 使用的模型 |
| apiKey | string | 模型 API Key |
| instruction | string | 系统提示词 |
| session | string | 从指定 sessionId 中加载会话项 |
| log | boolean | 是否开启日志记录，默认不开启 |

## 配置

用户可以在当前工作目录下保存 `.walle` 文件用于持久化参数配置。配置使用 JSON 格式。Agent 在启动时会读取配置作为参数。

## 命令行参数

用户可以通过在启动 Agent CLI 时指定参数来部分覆盖从配置文件中读取到的参数配置。

## 输出

对不同类型的响应内容采用不同的打印形式：

- 思考：使用流式输出思考内容，格式为：🤖 [思考中...]{思考内容}，思考内容输出完毕后，所有思考内容折叠为 [已思考 {n} 秒]。
- 回答：使用流式输出推理内容和回答内容，格式为：🤖 {回答内容}
- 工具调用：只输出工具名称，不需要输出工具参数，格式为：🤖 [使用工具]{工具名称}

过滤掉未处理的事件，不要打印出来。

## 日志

日志的记录为当前工作目录下的 `logs/{sessionId}.log`。

## 系统提示词

默认情况下，Agent 从工作目录下的 `WALLE.md` 中读取系统提示词并作为 `instruction` 参数。如果用户通过 `--instruction` 参数配置了系统提示词则覆盖从 `WALLE.md` 中读取到的系统提示词。
